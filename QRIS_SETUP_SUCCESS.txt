## 📝 Langkah Selanjutnya:

### 1. Edit file .env dengan informasi Anda:
Buka file .env dan ganti dengan data Anda:

PAYMENT_ACCOUNT_NAME=Nama_Anda
PAYMENT_ACCOUNT_NUMBER=No_HP_atau_Rekening
PAYMENT_BANK_NAME=Nama_Bank_atau_EWallet

Contoh untuk GoPay:
PAYMENT_ACCOUNT_NAME=Budi Santoso
PAYMENT_ACCOUNT_NUMBER=081234567890
PAYMENT_BANK_NAME=GoPay

Contoh untuk BCA:
PAYMENT_ACCOUNT_NAME=Budi Santoso  
PAYMENT_ACCOUNT_NUMBER=1234567890
PAYMENT_BANK_NAME=BCA

### 2. Tambahkan Gemini API Key:
GEMINI_API_KEY=your_api_key_here

Dapatkan gratis di: https://makersuite.google.com/app/apikey

### 3. Jalankan Bot:
npm start

### 4. Test:
- Scan QR code WhatsApp
- Kirim: /start
- Daftar: /daftar Nama_Anda
- Test nabung: /nabung 10000
