QRIS IMAGE PLACEHOLDER
======================

Anda perlu menyimpan gambar QRIS di folder ini dengan nama:
- qris-default.jpg (QRIS utama)
- qris-backup.jpg (QRIS cadangan, opsional)

Ukuran yang disarankan:
- Lebar: 500-800 px
- Format: JPG/JPEG
- Size: < 1 MB

Cara mendapatkan QRIS:
1. Buka aplikasi bank/e-wallet
2. Pilih menu Terima Pembayaran/QRIS
3. Screenshot QRIS Anda
4. Crop bagian QR code saja
5. Simpan di folder ini

PENTING:
- Jangan gunakan QRIS orang lain
- Gunakan rekening khusus untuk tabungan
- QRIS aman karena hanya untuk TERIMA uang
